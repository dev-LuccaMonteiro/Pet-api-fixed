## &#x20;About the Project

**Pet API - Fixed** is a project developed to provide an API for managing pet records. The application allows users to interact with pet data through HTTP requests, demonstrating the main operations of a REST API.

The project focuses on implementing and testing API endpoints, allowing users to create, retrieve, and delete pet records.

The API has been tested and is working, with its functionality demonstrated through screenshots and requests made using Postman.

## &#x20;Project Features

The API demonstrates the following functionalities:

- **GET:** Retrieve registered pet information.
- **POST:** Create and register a new pet.
- **DELETE:** Remove a registered pet.
- **API Response:** Return information after requests.
- **Data Management:** Manage pet records through API requests.

## &#x20;Getting Started

Follow these steps to access the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/dev-LuccaMonteiro/Pet-api-fixed.git
```

### 2. Navigate to the project directory

```bash
cd Pet-api-fixed
```

### 3. Open the application

Open the `techbyte.v1` directory in your preferred development environment.

### 4. Install dependencies

Install the dependencies required by the project according to its package or build configuration.

### 5. Run the API

Start the application using the execution command provided by its framework.

Once the application is running, use the configured local server address to send HTTP requests.

## 🔗 API Endpoints

The main operations demonstrated in this project are:

| Method | Functionality | Description                         |
| :----: | ------------- | ----------------------------------- |
|   GET  | Retrieve pets | Returns registered pet information. |
|  POST  | Create pet    | Registers a new pet.                |
| DELETE | Delete pet    | Removes a registered pet.           |

**Note:** Use the actual routes configured in the application when sending requests. The endpoint paths and request body depend on the API implementation.
